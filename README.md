## What this will be

Part of the **[HOTS Tools](https://hotstools.com)** family, alongside [HOTS Hosts](https://github.com/darsono6/HOTS) and [HOTS Hosts Lite](https://github.com/darsono6/HOTS-Hosts-Lite).

HOTS Uninstaller aims to work the way tools like Revo Uninstaller do: remove a program the normal way, then find and clean up what the installer left behind — leftover files, folders, and registry entries — instead of stopping once the uninstaller exits.

Planned areas:

- **Programs** — a cleaner list of installed Win32 programs, with a guided removal wizard (confirm → optional restore point → uninstall → scan and remove leftovers → summary)
- **Windows Apps** — the same guided removal for Appx/MSIX (Store) apps
- **Startup** — see and control what launches when Windows starts
- **Junk & cleanup** — find and clear out unnecessary files
- **Monitor** — keep track of what's installed and what changes

This list describes the plan, not finished features — it will change as the app takes shape.
